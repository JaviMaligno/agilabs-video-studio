# agilabs-video-studio

A Claude Code plugin that turns a blog article into a short, narrated, animated vertical
explainer video, rendered locally with Remotion in the AGILabs brand.

Install:

```
/plugin install agilabs-video-studio --marketplace JaviMaligno/agilabs-video-studio
```

Work in progress: skills, quickstart and a gallery still arrive with the first video.

- Template: [`template/`](template/) (Remotion project; `npm test` runs the unit tests)
- More at [javieraguilar.ai](https://javieraguilar.ai)
