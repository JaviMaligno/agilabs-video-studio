# How an AI agent forgets — long explainer for YouTube (EN) · script v1

Concept video, landscape 16:9, target ~10 min, with chapters. The long version of the short
`agent-memory-kinds`: same thread (a robot running a warehouse and one red slip, "SHELF 0: EMPTY"),
same five memories, each with its human counterpart and its own way of failing, but with room for
the evidence, the surprises and one mistake of my own. EN-only (ES column empty).

Sources (all javieraguilar.ai): "Compact or Look It Up" (scheduled 2026-12-11), "Explicit State
Doesn't Forget. It Misremembers.", "When the Fact Stops Being True", "Let the Loop Iterate",
"The Forgetting You Don't Measure", "Your Agent Doesn't Know What Has Already Happened",
"Beyond RAG: Building a Recursive Language Model". Quotes are from the published versions
(origin/main) and the compact-or-look-it-up branch; the source digest is in the session scratchpad.

**Chapters (YouTube):** 0 Intro · 1 What it learned · 2 The desk · 3 The gist · 4 The notebook ·
5 The form · 6 A flaw in my own test · 7 Which memory wins

**Retention:** a cold open with an open loop (the agent forgot; why?) paid off in chapter 7; a new
question at each chapter end; one surprise per chapter (old habits overrule the desk; a messy desk
is fine; the summary doesn't break; saving everything is the worst; a form is confidently wrong;
my own test was flawed).
